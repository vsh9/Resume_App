# Flutter Portfolio App

This is a simple one-page **resume/portfolio app** built using Flutter. Designed during my 2nd year of engineering, it highlights personal details, technical and creative skills, and a short introduction — all in a clean, mobile-friendly layout.

---

## Features

- Flutter-based responsive mobile UI
- One-page layout showcasing:
  - Profile photo
  - Name and Title
  - "About Me" section
  - Categorized Skills: Technical, Non-Technical, Creative

## Tech Stack

- **Flutter** (Dart)
- **Material Design**
- Platform: Android (can be adapted to iOS)

---

## How to Run

Make sure you have [Flutter](https://flutter.dev/docs/get-started/install) installed.

```bash
git clone https://github.com/yourusername/flutter-portfolio-app.git
cd flutter-portfolio-app
flutter pub get
flutter run
```
